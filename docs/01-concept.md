# 01. 企画

## 1. 背景と課題

車での移動が前提の地域では、飲み会の後は運転代行で帰るのが一般的だが、週末や繁忙期は代行の到着まで1〜2時間以上待つことがある（仮定：待ち時間の実態は試行の中で記録する）。

その間、次のことに困る。

- 店が閉まると待つ場所がない。冬は屋外や車内で待つのがつらい。
- 眠い・汗や匂いを流したい、という需要を満たす場所がない。
- 待ちきれずに飲酒運転をしてしまう動機になりうる。

客だけでなく、深夜に仕事を終えるスナックのキャストなど、店で働く側にも同じ困りごとがある。

## 2. 解決の方向

飲み屋街の近くに住む人（ホスト）が、自宅の寝床とシャワーを開放する。利用者（ゲスト）は仮眠やシャワーを済ませ、代行が着いたら帰る。代行がつかまらない場合は、アルコールが抜けるまで朝まで滞在できる。

## 3. 現在のステージ（ステージ0）

| 項目 | ステージ0の前提 |
|---|---|
| ホスト | 発案者本人の自宅 1 か所 |
| ゲスト | ホストが招待した人。知人のほか、スナックのキャストなど店経由で招待した人を含む |
| 費用 | 無償 |
| 利用時間 | 夜の受付開始から翌朝 10:00 まで |
| 入り方 | 暗証番号での解錠、またはホストによる遠隔解錠 |
| 法対応 | 無償で自宅に招く範囲で行い、制度対応はしない |
| トラブル対応 | システム上はホストに強い権限を持たせ、記録を残す。法的な措置はホスト自身の責任で行う |
| 代行との連携 | なし（ゲストが自分で代行を手配する） |

## 4. ステージ0で検証したいこと

1. **需要**：招待した人は実際に使うか。月に何回、どの曜日・時間帯か。
2. **使われ方**：滞在時間はどのくらいか。代行待ちの数時間か、朝までか。寝床とシャワーのどちらが求められるか。
3. **ホストの負担**：準備・対応・片付けの手間と、深夜から朝までの出入りは続けられる水準か。自動承認でホストが起きずに済む割合はどのくらいか。
4. **仕組みの要否**：LINE のやり取りだけで足りるのか、専用の仕組みがあると何が楽になるのか。

### 判断の目安

3 か月の試行で、利用が延べ 10 回以上あり、ホストが「続けられる」と判断できれば、ステージ1 に進む検討をする。

## 5. スコープ

**やること**

- 店で QR コードを見せる程度の手間でゲストを招待できる
- 今夜開放しているか、空きがあるかをゲストが確認できる
- ゲストが利用を申し込み、ホストが承認・辞退できる
- ホストが信頼済みとしたゲストは、ホストが就寝中でも自動で承認される
- 承認されたゲストに、住所・入り方を案内し、鍵を開けられるようにする
- 寝具・シャワー・トイレの使い方とハウスルールを、ホストが見たままの形で編集し、ゲストに周知できる
- 喫煙ルール（完全禁煙／電子タバコのみ可／ベランダ・屋外でのみ可）をホストが設定し、登録から滞在中まで繰り返しゲストに明示する
- 到着・退出・解錠・ホストの操作を記録し、後から振り返れる。トラブル時の証跡にもなる
- ホストが承認の取消、退去の要請、利用停止、鍵の無効化を即時に行える

**やらないこと（ステージ0）**

- 課金、決済
- 複数ホスト、ホストの募集
- 本人確認（身分証の確認）、ゲストからの評価・通報、保険
- 代行業者との連携（到着時刻の自動取得など）
- アルコールが抜けたかどうかの判定（運転できるかの判断はゲスト本人が行う）
- ネイティブアプリ

## 6. 段階計画

| ステージ | 内容 | 進む前に必要なこと |
|---|---|---|
| 0（現在） | 自宅 1 か所・招待制・無償 | — |
| 1 | ホストを数名に拡大 | ホスト間のルール統一、トラブル対応手順の共有 |
| 2 | 有償化・一般公開 | 旅館業法・公衆浴場法などの確認（行政・専門家への相談）、本人確認と安全対策、保険、代行連携 |

有償にした時点、または不特定の人を受け入れた時点で、法規制と安全の前提が変わる。朝までの滞在は「宿泊」と見なされやすいので、ステージ2 に進む前に必ず再検討する。

## 7. 決定済みの前提

- 寝床は 2 人分、シャワーは同時に 1 人
- 連絡手段は LINE
- 招待していない同行者は受け入れない
- 滞在は翌朝 10:00 まで

## 8. 未決事項

1. サービス名（本書では「代行待ちシェア」と仮称）
2. 新規の申込を受け付ける時間帯（本書では 21:00〜翌 3:00 と仮定。滞在は 10:00 まで）
3. 鍵の機種。第一候補は SwitchBot だが、実機での確認が要る（04-lock-selection.md）
4. 遠隔解錠を操作するのはホストだけでよいか（本書ではホストのみと仮定）
5. 同じ夜に面識のないゲスト同士が同室になることへの配慮。自動承認ではホストが相手を選べないので、「ほかに滞在者がいるときは自動承認しない」設定を既定で有効にするかどうか（本書では有効と仮定）
